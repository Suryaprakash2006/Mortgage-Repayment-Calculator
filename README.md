# Mortgage Repayment Calculator

A responsive React-based mortgage repayment calculator that helps users estimate monthly mortgage payments based on loan amount, interest rate, and repayment duration.

## Live Demo

https://suryaprakash2006.github.io/Mortgage-Repayment-Calculator/

## Features

- Calculate monthly mortgage repayments instantly
- Dynamic form validation and real-time updates
- Responsive and user-friendly interface
- Clean component-based React architecture
- Interactive financial calculation workflow

## Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

## Functionality

The application allows users to:

- Enter mortgage amount
- Select repayment duration
- Add interest rate details
- View estimated monthly repayments dynamically
- Interact with a responsive and intuitive UI

## Learning Outcomes

This project helped strengthen understanding of:

- React state management
- Form handling in React
- Component reusability
- Responsive frontend development
- User-centric UI design
